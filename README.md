# Rain Catcher

A small, responsive browser game about guiding rain into water cans. In Level 01, catch 30 drops before the 15-second timer ends to unlock Level 02, **The Eye**. Fill both cans while avoiding lightning to unlock Level 03, **The Storm**, where three labeled clouds must fill their matching jerry cans. Your score rewards catching water with fewer lines.

## Play

Open `index.html` in a modern browser. No build step or dependencies are required.

## Controls

- Select **Play**, then choose an unlocked level.
- Drag on the game scene to draw water-guiding lines. In **The Eye**, lines cannot cross the glowing lightning strikes.
- Select **Start the rain** to begin the 15-second round.
- In **The Eye**, read the lightning briefing and select **Enter the storm** to start.
- In **The Storm**, guide clouds A, B, and C to their matching cans. Clouds are arranged A–B–C from left to right; cans are C–B–A.
- Toggle **Hard mode** before drawing to limit lines: Level 01 allows one line up to 450 pixels, Level 02 allows one line with no length limit, and Level 03 allows three lines with no length limit. Reset the round to change the mode after drawing or starting the rain.
- Catching water triggers milestone messages at key drop counts during a round.
- Completing any level shows a thank-you message and a link to explore ways to get involved with charity: water.
- **Reset** clears the current round so you can redraw your route.
